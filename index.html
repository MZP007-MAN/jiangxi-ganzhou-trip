行程细节

DAY 0周五 · 轻松抵达

林厨当家 → 南湖 → 神金塔 → 格兰云天

13:30 广州出发，包车直达上犹，车程约 4.5–5 小时，车上可以小憩、游戏。18:30 在林厨当家吃客家菜，推荐酸酒鸭、客家酿豆腐、小炒鱼；20:00 饭后到南湖步道散步拍照；21:30 到神金塔附近吃烫皮、烧烤等夜宵，随后入住上犹格兰云天酒店。

DAY 1周六 · 红色打卡、速度与峡谷

石磨坊 → 清湖红色教育基地 → 非遗馆 → 卡丁车 → 园村 → 大金山漂流

08:30 在石磨坊吃古法豆浆、肠粉、炸米果；09:20 前往清湖红色教育基地，参观清湖暴动复原陈列馆、红色文化广场等核心区域，简要了解上犹革命历史并完成团队合照；10:15 到上犹非遗馆精华参观，了解九狮拜象、客家门匾、手工榨油等传承；11:00 到阳明国际赛车谷体验卡丁车竞速，长发需束起并听从安全培训；12:30 在园村吃农家菜，推荐时蔬、土鸡、笋干。

14:00 进行大金山漂流：全长约 3.5 公里，包含玻璃滑道和隧道漂，全程会湿身。务必准备全套干衣、毛巾、洞洞鞋和手机防水袋；终点有洗浴中心，漂完可以直接洗澡更衣。17:30 入住贝壳揽山居，19:00 在民宿内用晚餐，晚上打牌、唱 K 或休息均可自由安排。

DAY 2周日 · 玩水返程

自然醒 → 南湖水上运动 → 全鱼宴 → 广州

上午自然醒，在山间鸟鸣中享用民宿早餐；10:00 到南湖水上运动基地，可按小组选择桨板、摩托艇、香蕉船等项目。务必做好防晒，建议穿长袖水母衣或使用高倍防水防晒；12:30 就近吃南湖全鱼宴，体验石鱼、鳜鱼、银鱼汤；14:00 休整、收拾行李、擦拭装备，15:30 集合返程广州，预计晚上 20:00–21:00 抵达。
